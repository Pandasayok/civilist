# B2C: аккаунты и внутренний доступ

## Утверждено владельцем 20 октября 2026

- B2C, без организаций и кабинетов преподавателей.
- Email + пароль; обычный вход не требует одноразовой ссылки.
- Пробный доступ к ограниченным материалам — 72 часа после первого подтверждения email.
- Продление вручную; автоплатёж только при отдельном подключении пользователем.
- owner и sofia получают внутренний доступ без оплаты и срока окончания.
- Внутренний доступ не даёт права администратора. Роль Софьи остаётся learner.
- Учебный прогресс этих двух аккаунтов можно обнулить при необходимости. Это не требование удалить его; контент удалять нельзя.

## Первый PR: фундамент (реализовано здесь)

Добавочная миграция 0002 создаёт accounts и internal_access. Старые таблицы не меняются.
При загрузке приложения проверенная кодовая личность записывается с прежним ID.
Только существующие проверенные личности owner и sofia получают внутренний доступ.
Источник личности — прежняя серверная авторизация, а не параметры браузера.
Повторная загрузка не переписывает email и не восстанавливает отозванное право.
В профиле отображается бесплатный внутренний доступ. Роли по-прежнему определяются
серверной конфигурацией кодов. В этом PR нет создания пароля или изменения входа.

Значение access.kind=legacy обозначает прежний доступ по коду, НЕ trial или expired.
Этот PR не включает платный барьер и не ограничивает ранее доступные материалы.
При внедрении регистрации ensureLegacyAccount нужно вызывать только для проверенной
старой личности; публичная регистрация получает случайный серверный ID и не может
выбрать owner/sofia. Нельзя применять эту функцию к произвольному запросу регистрации.

## Следующие небольшие PR

1. Макеты/формы: регистрация, вход, подтверждение, восстановление, новый пароль.
2. Данные паролей и серверные сессии: безопасный хеш, rate limit, CSRF, отзыв сессий.
3. Почтовый адаптер: подтверждение email и восстановление; тестовый транспорт только
   локально. В production при отсутствии транспорта регистрация закрыта.
4. Перевод owner/sofia: подтверждение прежнего кода, привязка подтверждённого email,
   сохранение ID и внутреннего доступа. Не назначать роли из формы регистрации.
5. Пробный срок: одноразовый атомарный старт 72 часов, серверная проверка времени.
6. Серверная фильтрация доступных материалов. Проверить bootstrap и статические
   seed-импорты: закрытый контент и ответы не должны уходить клиенту.
7. QA: регистрация, повторный email, протухшие ссылки, восстановление, разные
   устройства, срок 72 часа, отсутствие доступа к чужим данным, внутренняя роль.

Тарифы и оплата — отдельная итерация. Окончание пробного доступа не удаляет аккаунт.

## Решения, которые ещё не утверждены

- Провайдер почты, адрес отправителя и домен. Без них реальная доставка писем не готова.
- Предложения: ссылка подтверждения 24 часа, восстановления 30 минут,
  повторная отправка через 60 секунд. Требуют согласования.
- Предложение: до 30 минут на завершение начатой попытки после срока. Не реализовано.
- Точный набор пробных материалов и ограничения шаблонов будут заданы владельцем.
