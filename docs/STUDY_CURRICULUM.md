# Учебный блок: первая итерация

## Реализовано

- Направление → раскрывающийся раздел → отдельная страница темы.
- Раздел берётся из поля `topic` опубликованного урока. В редакторе поле называется «Раздел оглавления».
- Раскрытый раздел сохраняется в URL; возврат из темы открывает именно его.
- Содержание темы с якорями, текстовые нормы без гиперссылок, переходы между соседними темами одного раздела.
- Поддерживаются старые прямые ссылки и идентификаторы уроков, сохраняется существующий прогресс.
- Никаких изменений базы, начального наполнения и юридических утверждений в этой итерации.

## Следующие итерации

- Полный конспект «Оферта и акцепт» по учебнику со сверкой актуальных норм; структурированные таблицы и схемы.
- Десять заданий по теме и отдельные итоговые тесты раздела с правилами прохождения.
- Сохранение места чтения и загрузка содержания по запросу: сейчас bootstrap всё ещё получает всю библиотеку.
- Наполнение остальных разделов. Пустые разделы сейчас не отображаются.

## Проверка на QA

1. Учиться → Гражданское право → Договорное право → Оферта и акцепт.
2. Проверить содержание, переход к примеру, обновление страницы, «Назад» браузера и «К оглавлению».
3. Завершить урок: состояние сохраняется после перезагрузки, повторные XP не начисляются.
4. Открыть карточки и задания темы; проверить, что существующие режимы продолжают работать.
5. Повторить навигацию на телефоне; проверить отсутствие горизонтальной прокрутки страницы.
6. Проверить существующий прогресс на QA. Продакшен этим PR не разворачивается.

Автоматические сценарии: `tests/ui/test_curriculum.py`. Выборочный запуск:
`npm run test:ui -- -k curriculum`.
