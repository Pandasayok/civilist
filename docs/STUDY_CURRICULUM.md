# Учебный блок: состояние реализации

Полный курс по трём учебникам **не завершён**. Карта оглавления не означает, что главы прочитаны и учебные материалы готовы.

## Что есть в этой ветке

- Карта 69 глав трёх томов: 104 темы в 14 разделах. Семейные и жилищные главы выделены в соответствующие направления. Это редакционный план, который можно уточнять.
- Шесть подготовленных тем раздела «Договорное право»: понятие и свобода договора; виды договоров; условия и форма; оферта и акцепт; переговоры и специальные способы заключения; изменение и расторжение.
- В каждой из этих тем четыре смысловых подраздела, пример, текстовые ссылки на нормы и десять заданий. Всего 60 заданий: 54 автоматически проверяемых, 6 письменных для самопроверки.
- Итоговый тест раздела: 20 проверяемых заданий из всех шести тем. Каждый запуск перемешивает задания; внутри активной попытки порядок сохраняется.
- Условия доступа: все темы раздела опубликованы, прочитаны и их тесты сданы. Пока есть неподготовленные темы, итоговый тест закрыт.
- Рабочий порог зачёта — 80% проверяемых ответов. Письменный ответ обязателен для завершения, но не входит в оценку; после сдачи показывается эталон для самопроверки. Это правило требует методического согласования владельцем.
- Отдельно сохраняются чтение темы, попытки теста, лучший результат и сдача раздела. Неудачная пересдача не отменяет ранее полученный зачёт.
- Ответы сохраняются при переходе между заданиями и кнопкой «Сохранить и к оглавлению». Несохранённое изменение текущего ответа может потеряться при обновлении страницы.
- Проверка ответа выполняется сервером. Разбор появляется после завершения. Это учебный тренажёр, не защищённая экзаменационная система: существующий bootstrap для свободной тренировки содержит банк с ответами.
- XP начисляется за первый успешный зачёт цели: 10 за тему, 30 за раздел. Повторная отправка и пересдача не увеличивают награду. Ошибки отражаются в существующем разделе повторения.

## Что ещё не готово

98 тем карты не получили полный новый комплект «конспект + 10 заданий». Старые короткие уроки, если совпадают с темами карты, остаются доступны, но не считаются выполнением нового стандарта. Остальные темы обозначены «Материал готовится». Итоговые тесты незаполненных разделов закрыты.

Полное чтение и анализ всех трёх учебников не выполнены. Для карты использованы оглавления; для договорного раздела — выбранные фрагменты главы 27 тома 1 и проверка норм ГК РФ. Нельзя представлять этот PR как завершение всего гражданско-правового блока.

Отдельные будущие задачи: загрузка уроков по запросу вместо общего bootstrap, сохранение позиции чтения, увеличенный независимый банк итоговых заданий, редакционная проверка всех конспектов и вопросов.

## Обновление базы и контента

Миграция `0001_assessments.sql` добавляет таблицу попыток и индексы. Старые таблицы и пользовательские записи не удаляются. Сначала применяются миграции, затем разворачивается Worker; штатный QA workflow уже выполняет этот порядок.

Пакет `content/course-contracts.json` импортируется при чтении контента. Повторный импорт безопасен. Существующие IDs сохранены. Старый опубликованный seed обновляется только при точном совпадении его исходного содержимого. Редакторские изменения, черновики и совпадения чужих IDs не перезаписываются. Конфликты выводятся администратору и могут оставить раздел неполным. Маркер импорта: `course:contracts-2026-10-05-v1`.

Развёртывание этой ветки на QA добавит подготовленные материалы как опубликованные **на QA**. Production отдельно не разворачивается.

## Проверка на QA

1. Развернуть `feat/study-curriculum` на QA после зелёного `Check Civilist`.
2. Открыть Учиться → Гражданское право → Договорное право. Должно быть шесть тем в порядке оглавления.
3. Открыть каждую тему: полный текст, таблицы/схемы, содержание, возврат к разделу; на телефоне таблица прокручивается внутри своего контейнера.
4. Прочитать тему, открыть «Тест темы · 10 заданий». В ответах на задания нет разбора до сдачи.
5. Заполнить два задания, выйти с сохранением, вернуться и обновить страницу. Ответы должны сохраниться.
6. Завершить тест. Проверить оценку, объяснения, письменную самопроверку, отсутствие гиперссылок на нормы в разборе.
7. Повторить отправку/обновить результат: XP не меняется. Пройти неудачную и успешную пересдачу, проверить лучший результат и ошибки.
8. До завершения всех шести тем итоговый тест закрыт. После их чтения и зачётов открывается 20 заданий; после успешной сдачи отображается «Раздел закрыт».
9. В другом разделе увидеть неподготовленные темы и заблокированный итоговый тест.
10. Администратор может редактировать структурированные части урока, таблицы и шаги без JSON. Проверить сохранение и повторное открытие.
11. Убедиться, что прежний прогресс пользователей сохранён. Учебные действия QA не должны появляться на основном сайте.

## Автопроверки

- `npm test`: правила оценивания, полнота комплектов, защита импорта от перезаписи редакторских правок и прежние проверки.
- `npm run test:integration`: временный Worker и свежая локальная D1; попытки, доступ пользователей, конкурирующие запросы, XP, блокировка итогового теста.
- `npm run test:ui`: Python + pytest + Playwright, временный Worker и D1. Новые сценарии — `tests/ui/test_assessments.py`.
- `npm run course:status`: отчёт по всем разделам. `npm run course:status -- --require-complete` намеренно завершится ошибкой, пока не подготовлен весь курс; обычная CI проверяет качество имеющегося пакета, а не объявляет весь курс готовым.

Сначала QA и содержательная проверка владельцем, затем merge и отдельное развёртывание production.
