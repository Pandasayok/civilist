# Проверка переноса

Проверено 2 октября 2026 года на Node.js 24.19.0 и Wrangler 4.92.0.

- Проверка TypeScript — без ошибок.
- Production-сборка React/Vite — успешна.
- Wrangler dry-run — Worker и статические ресурсы собираются; Worker около 422 KiB до сжатия.
- SQL-миграция применена к настоящей локальной D1.
- 9 тестов авторизации: роли, стабильный идентификатор, ошибочный код, подделка cookie, истечение сессии, отзыв при смене кода, изоляция одновременных запросов, выход, отказ при отсутствии секретов.
- 45 проверок локального Worker/API: вход и проверка Origin, закрытые маршруты, чтение учебной базы, сохранение профиля на двух сессиях, разделение ученик/администратор, проверка ответа, повторная отправка UUID, закладки, права редакции, черновик без автоматической публикации.
- Проверено исключение локальных секретов из Git.

Обнаруженные при проверке проблемы формата локальных секретов и даты совместимости исправлены. Дата совместимости закреплена на 2026-05-15, которую поддерживает используемый Wrangler; её не нужно менять на сегодняшнюю при каждом запуске.

В этом этапе не проверены браузерные сценарии на реальном телефоне, размещение в аккаунте владельца и перенос данных старой базы. После первой публикации нужны вход с двух устройств, несколько учебных действий и проверка сохранённого результата. На новом хостинге также нужно отдельно подключить еженедельную редакционную автоматизацию.
