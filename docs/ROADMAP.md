# Civilist — карта проекта

Состояние на 3 октября 2026 года, 21:51 по Москве. Статусы основаны на коде, пройденных проверках и результатах команд на Mac Дмитрия. Это снимок прогресса, а не автоматически обновляемый отчёт.

Цель: приложение для обучения Софьи с доступом с телефона и компьютера, сохранением прогресса и возможностью вместе дорабатывать код через GitHub. Первый запуск — в рамках бесплатных тарифов Cloudflare Workers и D1.

## Что за что отвечает

| Часть | Простое объяснение |
|---|---|
| Mac | Рабочий стол: здесь редактируем, проверяем и собираем приложение. |
| GitHub | Хранилище кода и истории: видим каждое изменение и можем вернуться к прошлой версии. |
| Cloudflare Workers | Компьютер в интернете, который обслуживает сайт. После запуска Mac можно выключить. |
| Cloudflare D1 | Общая тетрадь приложения: материалы, ответы, закладки и прогресс. |
| Коды входа | Отдельные ключи для администратора Дмитрия и ученицы Софьи. |
