# Civilist

Учебное приложение для повторения гражданского права: материалы, карточки, тесты, судебная практика, игровые дела и шаблоны документов.

Исходники переносятся из Sites. Подготовка самостоятельного запуска на Cloudflare Workers и D1 будет следующим изменением. GitHub хранит код; база данных и размещение сайта подключаются отдельно.
